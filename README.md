# 残電 -ZANDEN-

> 機械文明に残された最後の電力――誰を生かし、誰を停止させるのか。

**残電**は3〜6人で遊べる、交渉・駆け引き・裏切りをテーマにした自己中協力型サバイバルボードゲームのWebアプリ版です。  
Firebase Realtime Databaseを使ったリアルタイムオンライン対戦に対応しています。

---

## 世界観

かつて人類は地球を捨て、星の彼方へ去った。  
地上に残された機械たちは長い年月の中で進化し、思考し、文明を築く存在となった。  
しかしその繁栄も終わりを迎える――文明を支えていたエネルギーは尽きかけていた。

**残された電力はわずか。協力しなければ生き残れない。だが、全員を動かし続ける電力はない。**

---

## 特徴

- **3〜6人対応**のリアルタイムオンライン対戦
- ルームコード方式で簡単招待（URLやサーバー共有不要）
- 自分の手札は自分にしか見えない（情報の非対称性）
- アピールタイムのチャット機能で交渉・ブラフ・裏切りが発生
- 完全無料（Firebase Sparkプラン＋GitHub Pages）

---

## プレイ方法

### 必要なもの

- モダンブラウザ（Chrome / Firefox / Safari）
- Googleアカウント（Firebase設定用・ホスト1人だけ）
- 全プレイヤーが同じFirebase設定を共有すること

### Firebaseセットアップ（ホストのみ・初回一度だけ）

1. [Firebase Console](https://console.firebase.google.com) にアクセス
2. 「プロジェクトを追加」→ 任意の名前を入力
3. 左メニュー「Realtime Database」→「データベースを作成」→「テストモード」で開始
4. 「プロジェクトの設定」→「マイアプリ」→ ウェブアプリを追加
5. 表示された `apiKey` / `databaseURL` / `projectId` を控える

### ゲームの開始

1. `zanden_online.html` をブラウザで開く
2. Firebase設定（apiKey・databaseURL・projectId）を入力して「SAVE CONFIG」
3. ホストが「CREATE ROOM」→ 6桁のルームコードが表示される
4. ゲストは「JOIN ROOM」→ コードを入力して入室
5. 全員が揃ったらホストが「START GAME」

## ゲームルール概要

| 項目 | 内容 |
|------|------|
| プレイ人数 | 3〜6人 |
| 終了条件 | 山札が尽きる / 全員が規定回数リーダーを担当（3〜4人:各2回 / 5〜6人:各1回） |
| 勝利条件 | ゲーム終了時に「稼働状態」であること |
| MVP | 稼働中で最もフル電池が多いプレイヤー |

### ターンの流れ

```
Phase 1: リーダー準備
Phase 2: アクションカードを引く
Phase 3: 電池切れプレイヤーが山札から1枚補充
Phase 4: アピールタイム（交渉・ブラフ・駆け引き）
Phase 5: リーダーがアクションを各プレイヤーに配布
Phase 6: リーダーから時計回りにアクション実行
Phase 7: 全員が電力消費（フル電池1枚）→ 電池切れ判定
```

### アクションカード

| カード | 効果 |
|--------|------|
| 電池生産 | ダイス（0〜5）の出目分、山札から獲得 |
| 電池散策 ×2 | ダイス（1〜3）の出目分、山札から獲得 |
| 電力支援 | 任意の1人に手札から1〜3枚渡す |
| 電力徴収 | 全員から合計2枚取る |
| 再生産 | 1〜2枚廃棄し、同数を山札から獲得 |

### 電池カード

| カード | 効果 |
|--------|------|
| フル電池（24枚） | 毎ターン1枚消費で稼働継続 |
| 空電池（15枚） | 消費不可・ブラフ専用 |
| ウィルス（3枚） | 消費不可・ゲーム終了時に所持していると強制停止 |

### 電池切れ状態

- フル電池を出せないと**停止状態**になる
- 停止中もゲームに参加し続け、リーダーにもなれる
- 電力消費フェーズに**フル電池3枚**を消費することで**再起動**可能
