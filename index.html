GAME RULES

■ 目的
ゲーム終了時に「稼働状態」のプレイヤーが勝利。稼働中で最もフル電池が多いプレイヤーがMVP。

■ 終了条件
・山札が尽きたターンの電力消費判定終了時
・全員が規定回数リーダーを担当した時 (3〜4人:各2回 / 5〜6人:各1回)

■ ターンの流れ
Phase1:リーダー準備 → Phase2:アクション引く → Phase3:電池切れ補充
→ Phase4:アピールタイム → Phase5:アクション配布 → Phase6:アクション実行
→ Phase7:電力消費判定 → 次ターン

■ アクション
・電池生産：ダイス(0〜5)で山札から獲得
・電池散策×2：ダイス(1〜3)で山札から獲得
・電力支援：任意の1人に1〜3枚渡す
・電力徴収：全員から計2枚取る
・再生産：1〜2枚廃棄し同数獲得

■ 電池カード
フル電池：毎ターン1枚消費で稼働継続 / 空電池：消費不可・ブラフ専用
ウィルス：消費不可・ゲーム終了時所持で強制停止

■ 電池切れ
停止中もゲーム参加・リーダー担当可。フル電池3枚消費で再起動。
